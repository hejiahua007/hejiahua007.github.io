A NOTE IN THE GARDEN

灵伴桌面宠物 (Ling Pet) — 产品需求文档 v2.0

2026年08月05日 项目 / 桌面宠物

版本: 2.0
日期: 2026-08-05
状态: 草案
目标平台: Steam (Windows)
上架定位: 桌面伴侣 + 任务自动化工具，面向全球普通用户

1. 产品愿景

灵伴桌面宠物 v2.0 将从一个开发者自用的 Electron 桌面工具，升级为一款面向全球普通用户的 Steam 桌面伴侣应用。

用户拥有一只可爱的虚拟桌面宠物，它不仅仅是装饰——它还能帮助用户管理日常习惯（喝水提醒、番茄钟、定时休息）、执行简单的桌面自动化任务，成为用户桌面上有”温度”的智能伙伴。

核心价值主张: “桌面上有生命的伙伴——好看、好用、好习惯”

差异化定位: Steam 上缺乏将”桌面宠物 + 实用任务自动化”结合的轻量应用。v2.0 将填补这一空白，面向非技术用户降低使用门槛。

2. 目标用户画像

用户类型 A：桌面美化爱好者（占比约 45%）

属性 描述
年龄 16-28 岁
特征 喜欢美化桌面、使用 Rainmeter/Wallpaper Engine、二次元文化爱好者
痛点 现有桌面宠物功能单一，只有观赏价值
需求 可自定义的可爱宠物 + 一定的实用性
Steam 行为 浏览 Wallpaper Engine 工坊、购买独立游戏
付费意愿 中，愿意为高质量美化工具付费 ($5-$10)

用户类型 B：效率工具用户（占比约 30%）

属性 描述
年龄 22-40 岁
特征 知识工作者、程序员、远程办公者
痛点 长时间工作忘记休息、需要轻量定时提醒但不想装重型软件
需求 番茄钟、定时提醒、简单的自动化脚本执行
Steam 行为 同时使用效率工具和游戏
付费意愿 高，愿意为提升工作效率付费 ($10-$15)

用户类型 C：轻量 PC 用户（占比约 25%）

属性 描述
年龄 18-50 岁
特征 普通电脑用户，不熟悉命令行和脚本
痛点 需要定时提醒（吃药、喝水、休息），但不知道如何设置
需求 开箱即用的提醒功能、简单友好的界面
Steam 行为 轻度 Steam 用户
付费意愿 低-中，冲动消费型 ($3-$8)

3. 核心功能列表

3.1 P0 — 上架 Steam 最低要求

编号 功能 状态 说明
P0-01 透明桌面宠物窗口（拖拽/缩放/互动） 保留增强 现有功能，需优化性能和无障碍
P0-02 宠物动画系统（呼吸/摇摆/点击反馈） 保留 现有功能良好
P0-03 自定义宠物形象（PNG/JPG/GIF/WebP/APNG） 保留增强 增加 Steam 工坊支持
P0-04 定时任务系统（通用模板） 重构 移除 Wallpaper Engine 硬编码，改为通用模板
P0-05 任务调度执行（PowerShell 脚本） 保留 核心功能，保持现有机制
P0-06 控制中心 UI 重构 重新设计，面向普通用户
P0-07 系统托盘 + 右键菜单 保留增强 精简菜单，优化交互
P0-08 开机自启动 保留 已实现
P0-09 首次启动引导向导 新增 帮助新用户快速上手
P0-10 清理一次性代码 新增 移除旧任务迁移、Wallpaper Engine 硬编码
P0-11 国际化框架 (i18n) 新增 至少支持英文、简体中文
P0-12 Steam 集成基础（Overlay、云存档） 新增 使用 Steamworks SDK 或 greenworks
P0-13 安装包签名与合规 新增 符合 Steam 分发要求

3.2 P1 — 提升竞争力

编号 功能 状态 说明
P1-01 内置任务模板库（≥10个通用模板） 新增 喝水提醒、番茄钟、眼保健操、定时关机等
P1-02 多宠物支持 新增 同时展示多只宠物，不同宠物绑定不同任务
P1-03 宠物动画扩展 新增 更多互动动画（睡觉、吃饭、生气等状态）
P1-04 任务执行历史面板 新增 可视化查看历史执行记录
P1-05 主题系统（浅色/深色/自定义） 新增 不只深色主题，支持更多视觉风格
P1-06 宠物商店/画廊 新增 内置宠物形象选择器，Steam 工坊下载
P1-07 成就系统 新增 Steam 成就（连续打卡、自定义宠物等）
P1-08 桌面通知增强 增强 支持富文本通知、任务执行结果预览
P1-09 任务支持 Cron 表达式 增强 除每日时间外，支持更灵活调度
P1-10 数据导出/导入 新增 任务配置迁移
P1-11 性能优化 增强 降低 CPU/内存占用，优化动画帧率

3.3 P2 — 后续迭代

编号 功能 状态 说明
P2-01 Steam 创意工坊完整集成 新增 用户上传/下载宠物形象和任务模板
P2-02 DLC 宠物包 新增 主题宠物包（节日限定、IP 联动等）
P2-03 宠物 AI 对话（LLM 集成） 新增 可选的 AI 聊天伙伴功能
P2-04 云端配置同步 新增 Steam 云存档增强，跨设备同步
P2-05 手柄/游戏控制器支持 新增 通过手柄与宠物互动
P2-06 macOS 平台适配 新增 扩展到 Mac 用户
P2-07 社区翻译贡献 新增 通过 Steam 社区翻译
P2-08 插件系统 新增 允许社区开发任务类型扩展

4. 非功能需求

4.1 性能要求

编号 需求 指标
NF-P01 CPU 占用 空闲时 < 1%，动画播放时 < 5%（单核）
NF-P02 内存占用 < 150MB（含 Electron 运行时）
NF-P03 启动时间 冷启动 < 3 秒（SSD）
NF-P04 动画帧率 稳定 60fps（支持显示器刷新率）
NF-P05 安装包大小 < 120MB（Electron + 资源）

4.2 安全要求

编号 需求 说明
NF-S01 IPC 通信安全 保持 contextBridge + file:// 校验
NF-S02 脚本沙箱执行 PowerShell 脚本在用户权限内执行，不请求管理员权限
NF-S03 CSP 策略 保持严格内容安全策略
NF-S04 无远程代码执行 不加载远程脚本，所有资源本地化
NF-S05 用户数据加密 敏感配置可选用 AES 加密

4.3 无障碍要求

编号 需求 说明
NF-A01 键盘导航 控制中心支持完整键盘操作
NF-A02 屏幕阅读器 关键 UI 元素提供 aria 标签
NF-A03 动画控制 保持 prefers-reduced-motion 支持
NF-A04 高对比度 支持 Windows 高对比度主题
NF-A05 字体缩放 支持系统字体缩放设置

4.4 国际化要求

编号 需求 说明
NF-I01 多语言框架 使用 i18next 或类似方案
NF-I02 首批语言 英文（默认）、简体中文
NF-I03 UI 文本分离 所有用户可见文本提取到语言文件
NF-I04 RTL 预留 架构支持未来 RTL 语言

4.5 可靠性要求

编号 需求 说明
NF-R01 配置容错 保持现有 JSON 损坏自动恢复
NF-R02 原子写入 保持现有 .tmp → rename 策略
NF-R03 崩溃恢复 异常退出后自动恢复宠物状态
NF-R04 任务执行隔离 单个任务失败不影响调度器和其他任务

5. v1.0 → v2.0 差异对照表

维度 v1.0（当前） v2.0（目标）
目标用户 开发者 / Wallpaper Engine 用户 全球普通 PC 用户
分发渠道 手动安装包 (NSIS) Steam 商店
内置任务 3 个 Wallpaper Engine 模板 10+ 通用生活/工作模板
任务迁移 旧 Windows 计划任务迁移 移除，新用户无需此功能
宠物形象 本地文件自定义 Steam 工坊 + 本地自定义
UI 设计 开发者风格深色主题 面向普通用户的友好界面
首次体验 无引导 首次启动引导向导
语言 仅中文 英文 + 中文（i18n 框架）
成就系统 无 Steam 成就
云存档 无 Steam 云存档
许可协议 UNLICENSED / MIT 商业许可
宠物数量 单只 支持多只
任务调度 仅 HH:mm 每日一次 HH:mm + Cron 表达式
代码质量 含一次性代码 干净、模块化、可维护

6. 用户故事（关键场景）

US-01: 首次体验

作为一名桌面美化爱好者，我下载并启动灵伴后，看到一个友好的引导向导，帮我选择宠物形象、设置第一个提醒任务，5 分钟内就能让宠物在桌面上活起来。

US-02: 每日习惯养成

作为一名上班族，我设置了喝水提醒（每小时）、午休提醒（12:30）、眼保健操（15:00），宠物会在对应时间通过动画和通知提醒我，帮我养成健康习惯。

US-03: 宠物个性化

作为一名二次元爱好者，我从 Steam 工坊下载了喜欢的动漫角色宠物形象，还可以自己制作 GIF 宠物，让桌面独一无二。

US-04: 任务自动化

作为一名程序员，我创建了自定义脚本任务：每天 18:00 自动拉取 Git 仓库、每周五 17:00 备份项目文件夹。宠物用动画告诉我任务执行结果。

7. 成功指标

指标 目标值 衡量方式
Steam 好评率 ≥ 85% Steam 评价
7 日留存率 ≥ 40% 内置遥测（可选，需隐私合规）
首次引导完成率 ≥ 80% 引导流程追踪
任务创建率 ≥ 60% 用户创建 ≥1 个任务 内置统计
崩溃率 < 0.5% 崩溃报告
支持工单 < 50/月 客服统计

8. 风险评估

风险 等级 缓解措施
Steam 审核不通过 中 提前阅读 Steamworks 文档，确保合规
Electron 体积过大 低 120MB 在 Steam 可接受范围内
PowerShell 安全顾虑 高 默认仅提供无害模板，脚本编辑需用户确认
竞品冲击 中 差异化定位（宠物 + 实用），持续更新
国际化工作量 中 首批仅中英文，后续社区贡献
用户留存低 中 成就系统、每日打卡、宠物养成机制
