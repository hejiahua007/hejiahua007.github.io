A NOTE IN THE GARDEN

灵伴桌面宠物 — 商业化路线图

2026年08月05日 项目 / 桌面宠物

日期: 2026-08-05
商业模式: 买断制 + 可选 DLC
目标平台: Steam (Windows)

1. Steam 上架策略

1.1 上架准备清单

阶段 事项 说明 预计耗时
前期准备 Steamworks 开发者注册 支付 $100 注册费，完成税务和身份验证 1-2 周
商店页面 创建商店页面 宣传文案、截图、预告片、标签 2-3 周
技术集成 Steam SDK 集成 greenworks + 云存档 + Overlay 2-3 周
测试阶段 Steam Playtest 邀请测试者，收集反馈 2-4 周
审核提交 提交审核 商店页面 + 构建版本审核 1-2 周
预热宣传 愿望单活动 社交媒体、社区宣传 持续
正式发布 上线 Steam 发布日运营 1 天

1.2 Steam 商店页面策略

标签 (Tags) 建议

主要标签:
  - Utilities (工具)
  - Cute (可爱)
  - Casual (休闲)
  - Software (软件)

次要标签:
  - Automation (自动化)
  - Productivity (效率)
  - Anime (动漫)
  - Customization (自定义)

截图要点

截图编号 内容
1 桌面全景：宠物在桌面上 + 气泡提醒效果
2 控制中心首页 Dashboard
3 宠物选择界面（展示多种宠物形象）
4 提醒设置界面（展示模板库）
5 自定义宠物形象效果

预告片脚本 (30-60秒)

[0:00-0:10] 空桌面 → 宠物出现 → 动画展示
[0:10-0:20] 用户点击互动 → 爱心粒子效果
[0:20-0:30] 打开控制中心 → 选择宠物形象
[0:30-0:40] 设置提醒 → 任务执行展示
[0:40-0:50] 多种宠物展示 + 主题切换
[0:50-0:60] Logo + 商店链接

商店文案核心卖点

英文:
  "A cute desktop companion that actually helps you build good habits!"
  
  Features:
  - Adorable animated desktop pets
  - Smart reminders for hydration, breaks, and more
  - Customizable pet appearances (GIF/APNG supported)
  - Lightweight & always on top
  - Steam Cloud Save & Achievements

中文:
  "不只是桌面宠物——还能帮你养成好习惯！"
  
  特色：
  - 可爱的动态桌面宠物
  - 智能提醒：喝水、休息、定时关机
  - 支持 GIF/APNG 自定义宠物形象
  - 轻量、置顶、不干扰工作
  - Steam 云存档 & 成就系统
