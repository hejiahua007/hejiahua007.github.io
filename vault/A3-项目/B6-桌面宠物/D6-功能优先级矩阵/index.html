P0 功能详细拆分

P0-01: 清理一次性代码（工作量: M，3-4天）

子任务 涉及文件 描述
移除 Wallpaper Engine 硬编码 src/config-store.js:7-51 删除 WALLPAPER_ENGINE 常量、wallpaperScript() 函数
重写内置任务模板 src/config-store.js:53-89 将 3 个 WE 任务替换为通用模板
移除旧任务迁移系统 src/main.js:450-469 删除 adoptLegacyTasks() 函数
移除迁移 IPC 通道 src/main.js:538 删除 legacy:adopt handler
移除 preload 迁移 API src/preload.js:29 删除 adoptLegacyTasks
移除迁移 UI 面板 src/manager.html:56-61 删除 .migration-card 面板
移除迁移 JS 逻辑 src/manager.js:15-16,114-186 删除 adoptLegacy 相关变量、事件处理
移除 legacyTasksAdopted 设置 src/config-store.js:118 删除 legacyTasksAdopted 默认值
更新集成测试 tests/integration.js:15-16 适配新的默认任务模板

P0-02: 通用内置任务模板（工作量: M，2-3天）

任务模板 默认时间 脚本描述
晨间唤醒 07:00 显示系统通知”早安！新的一天开始了”
喝水提醒 10:00 每小时显示一次喝水提醒通知
午休提醒 12:30 通知提醒午休时间
眼保健操 15:00 提醒做眼保健操并打开计时器
每日总结 18:00 显示通知提醒写工作日志
晚间放松 21:00 提醒放松休息
定时关机 23:00 15分钟后自动关机

所有模板默认关闭，用户首次使用时通过引导向导选择性启用。

P0-03: 首次启动引导向导（工作量: M，3-4天）

步骤 内容
步骤1: 欢迎 应用简介，选择语言
步骤2: 选择宠物 从内置形象中选择或跳过
步骤3: 快速设置 开机自启、总在最前、动画效果
步骤4: 选择任务 从模板库中勾选想要的任务
步骤5: 完成 操作提示（如何与宠物互动）

P0-04: 控制中心 UI 重设计（工作量: L，6-8天）

参见 07-UI-UX改版方案.md 详细设计。

P0-05/06: 国际化（工作量: M，3-4天）

技术方案 说明
框架 i18next + i18next-fs-backend
语言文件 locales/zh-CN.json, locales/en-US.json
翻译范围 所有 UI 文本、通知、错误提示、内置模板描述

P0-07: Steam 基础集成（工作量: L，7-10天）

功能 方案
Steamworks SDK 集成 使用 greenworks (Node.js Steamworks 绑定)
Steam Overlay 宠物窗口排除 Overlay，控制中心启用
Steam 云存档 将 config.json 纳入云存档范围
启动参数 --steam 参数区分 Steam 版本
