# Signal Radar：证据约束的信息求索平台

## 一句话介绍

`signal-radar` 是一个本地优先、证据约束的信息求索平台，以中国住宅地产基本面作为首个领域模板。

## 工作流

产品固定围绕“原始数据拉取 → 推演趋势 → 准备预案”展开，并在默认 30 天后使用新证据复盘旧推演。外部系统可以把估值状态作为输入，但雷达只回答基本面证据支持、反驳还是不足。

## 已实现

- RSS/Atom 与受控 HTTP JSON 两类采集适配器；
- SQLite 事实源、去重、全文检索和不可变证据快照；
- FastAPI 研究任务与结构化研究包接口；
- Electron + Vue 桌面工作台；
- 预案版本、到期复盘和历史轨迹；
- 无模型密钥时可使用确定性规则完成离线样例演示。

## 边界

项目不是荐股、估值或自动交易系统。仓库示例数据是合成固定样例，不代表实时市场数据；远程来源必须显式批准并遵守访问规则。
