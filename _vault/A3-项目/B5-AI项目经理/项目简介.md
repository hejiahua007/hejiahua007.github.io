# 企业微信 AI 项目经理

## 一句话介绍

`wecom` 是一个 Windows 优先的本地项目驾驶舱，把一个本地项目目录、一个企业微信群和一个可启停的 AI 项目经理运行实例绑定起来。

## 已实现

- V1 命令行机器人：企业微信 WebSocket、历史消息补拉、DeepSeek、消息去重和阶段总结；
- V2 桌面端：Electron + Vue 3 + TypeScript + Element Plus；
- 项目运行实例可启动、停止和切换，停止时会清理模型、历史同步与总结任务；
- AI 只读项目的 `docs`、`plan`、`tmp` 文本资料，正式文档保持只读，草稿只写入限定位置；
- Bot 与模型凭证使用 Electron `safeStorage` 保存，不进入渲染进程或公开文档；
- 支持观察、审核、主动三种工作模式以及群白名单。
