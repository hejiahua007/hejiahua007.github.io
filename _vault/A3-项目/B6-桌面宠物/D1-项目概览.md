# 灵伴桌面宠物

## 一句话介绍

`ling-pet` 是一个面向 Windows 的透明桌面宠物和可编辑脚本任务管理器。

## 已实现

- 透明无边框宠物窗口，可拖动、缩放、隐藏和显示；
- 呼吸、轻摆、点击跳动与爱心粒子效果；
- 支持 PNG、JPG、GIF、WebP、APNG 自定义形象；
- 系统托盘和右键菜单；
- 可新增、编辑、删除和立即运行 PowerShell 定时任务；
- 开机自启动、置顶、位置与尺寸持久化；
- 通过 electron-builder 生成 Windows x64 NSIS 安装包。

## 安全与边界

渲染页面启用了上下文隔离、沙箱和内容安全策略，不加载远程内容。任务脚本拥有当前 Windows 用户权限，因此只应运行自己编写或确认可信的脚本。项目清单当前标记为 `UNLICENSED`，公开简介不宣称开源许可。
