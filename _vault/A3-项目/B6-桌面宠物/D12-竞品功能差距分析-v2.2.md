## 本次实现方案（5个模块）

### 模块 1: 宠物养成系统
- **好感度系统**: 点击互动 +1 好感度，连续登录 +2，完成任务 +3
- **心情状态**: 😊开心 / 😐一般 / 😢低落（根据互动频率）
- **等级成长**: Lv.1 → Lv.10，每级解锁新动画/新气泡
- **喂食功能**: 右键菜单新增"投喂"按钮，宠物吃食物动画
- 数据存储: config.json 新增 `petStatus` 字段

### 模块 2: 白噪音/环境音播放器
- 5 种内置音效: 雨声、咖啡馆、篝火、海浪、森林
- 纯前端 Audio API 播放（无需额外依赖）
- 番茄钟专注模式下自动播放
- 音量控制、循环播放
- 宠物气泡显示当前音效

### 模块 3: 习惯打卡追踪
- 预设 6 种习惯: 早起、运动、阅读、冥想、日记、早睡
- 7 天日历视图
- 今日打卡 + 连续天数统计
- Dashboard 嵌入习惯组件
- 数据存储: config.json 新增 `habits` 字段

### 模块 4: 迷你小游戏
- "接住掉落的爱心" — 30 秒限时小游戏
- 宠物窗口内运行，爱心从上方掉落
- 鼠标点击接住，分数统计
- 作为专注休息时的解压工具
- 最高分 localStorage 持久化

### 模块 5: 桌面 Widget 小组件
- 数字时钟 Widget（可拖拽、可缩放）
- 简洁日期显示
- 独立透明窗口
- 右键切换 12h/24h 格式
- 可与宠物窗口分离显示

## 技术方案

| 模块 | 技术 | 存储 |
|---|---|---|
| 宠物养成 | IPC + config-store | config.json |
| 白噪音 | HTML5 Audio API (base64 音频) | 无 |
| 习惯打卡 | config-store + 日历算法 | config.json |
| 迷你游戏 | Canvas API / DOM 动画 | localStorage |
| Widget | 新 BrowserWindow (透明无边框) | 无 |
