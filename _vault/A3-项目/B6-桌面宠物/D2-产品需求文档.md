# 灵伴桌面宠物 — 产品需求文档 (PRD)

## 1. 产品愿景

打造一款兼具陪伴感与实用性的 Windows 桌面工具——用户拥有一个可互动的虚拟宠物，同时借助内置的定时任务系统养成良好生活习惯。

## 2. 目标用户

- 喜欢桌面美化、虚拟宠物的用户
- 需要定时提醒/自动化任务的 Windows 用户
- 希望通过可视化方式管理 PowerShell 脚本的用户
- 对 Wallpaper Engine 有定时控制需求的用户

| 需求编号 | 需求描述 |
|---|---|
| NF-01 | 配置文件原子写入，防止数据损坏 |
| NF-02 | IPC 通信安全校验（仅允许 file:// 协议） |
| NF-03 | 支持 `prefers-reduced-motion` 无障碍设置 |
| NF-04 | 安装包大小控制在 100MB 以内 |
| NF-05 | 任务执行不阻塞主进程 |
