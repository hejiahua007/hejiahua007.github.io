# 灵伴桌面宠物 — 商业化路线图

> **日期**: 2026-08-05  
> **商业模式**: 买断制 + 可选 DLC  
> **目标平台**: Steam (Windows)

---

## 1. Steam 上架策略

### 1.1 上架准备清单

| 阶段 | 事项 | 说明 | 预计耗时 |
|---|---|---|---|
| **前期准备** | Steamworks 开发者注册 | 支付 $100 注册费，完成税务和身份验证 | 1-2 周 |
| **商店页面** | 创建商店页面 | 宣传文案、截图、预告片、标签 | 2-3 周 |
| **技术集成** | Steam SDK 集成 | greenworks + 云存档 + Overlay | 2-3 周 |
| **测试阶段** | Steam Playtest | 邀请测试者，收集反馈 | 2-4 周 |
| **审核提交** | 提交审核 | 商店页面 + 构建版本审核 | 1-2 周 |
| **预热宣传** | 愿望单活动 | 社交媒体、社区宣传 | 持续 |
| **正式发布** | 上线 Steam | 发布日运营 | 1 天 |

## 4. 版本迭代计划

### 4.1 版本路线图

```
v2.0 MVP (12周) ──→ v2.1 增强 (8周) ──→ v2.2 扩展 (8周) ──→ v3.0 平台化 (12周)
    │                    │                    │                    │
    │                    │                    │                    │
    └─ Steam 上架        └─ 多宠物+成就      └─ 工坊+主题        └─ AI+插件+Mac
```

### 4.2 v2.0 — MVP (目标: 12 周)

| 功能模块 | 说明 |
|---|---|
| 代码清理 | 移除所有一次性代码和 Wallpaper Engine 绑定 |
| 通用任务模板 | 7 个内置通用模板 |
| UI 重设计 | 新的控制中心 Dashboard |
| 引导向导 | 首次启动 4 步引导 |
| 国际化 | 中英文支持 |
| Steam 基础集成 | 云存档、Overlay |
| Steam 商店页面 | 文案、截图、预告片 |

**发布目标**: Steam Early Access 或正式发布

### 4.3 v2.1 — 增强 (目标: +8 周)

| 功能模块 | 说明 |
|---|---|
| 多宠物支持 | 同时 1-3 只宠物 |
| Steam 成就系统 | 15-20 个成就 |
| 宠物动画扩展 | 5+ 新动画 |
| 任务历史面板 | 可视化执行历史 |
| 数据导入/导出 | 任务配置迁移 |
| 性能优化 | CPU/内存/启动速度 |

### 4.4 v2.2 — 扩展 (目标: +8 周)

| 功能模块 | 说明 |
|---|---|
| Steam 创意工坊 | 用户上传/下载宠物形象 |
| 主题系统 | 3-5 种 UI 主题 |

| Cron 表达式 | 灵活的任务调度 |
| 更多语言 | 日语、韩语、德语等 |
| DLC 宠物包 Vol.1 | 首发付费 DLC |

### 4.5 v3.0 — 平台化 (目标: +12 周)

| 功能模块 | 说明 |
|---|---|
| 宠物 AI 对话 | 可选的 LLM 聊天 |

## 7. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| Steam 审核不通过 | 低 | 高 | 提前研究审核指南，准备申诉材料 |
| 销量不及预期 | 中 | 高 | 控制成本、灵活定价、加强推广 |
| 负面评价集中出现 | 中 | 中 | 快速响应修复、社区沟通 |
| 竞品突然出现 | 低 | 中 | 差异化功能、快速迭代 |
| 技术债务积累 | 中 | 中 | 每版本预留 20% 时间做重构 |
| Electron 安全漏洞 | 低 | 高 | 及时升级 Electron 版本 |
