# 本地项目总览

## 整理原则

- “已实现”只描述仓库中已经存在的能力，不把计划写成成果。
- 涉及投资的项目只提供研究和计划支持，不构成投资建议，也不执行自动交易。
- AI、企业微信与个人资料项目不公开凭证、群聊、运行数据库和私人内容。
- 训练类项目会区分“已有脚本”和“已经验证的产品”，避免把实验仓包装成成品。
