# Life Vault：极简人生记录活跃仓

## 一句话介绍

`life-vault` 是公司电脑与宿舍电脑之间的当月记录中继站，目标是在低能量状态下也能用一分钟留下真实记录。

## 核心方法

系统从僵化的长期计划转向“记录 → 趋势 → 预案”：先留下实际发生的事情，再定期观察行为和状态如何变化，最后为可能出现的情景准备下一步，而不是要求每天严格执行完整计划。

## 当前结构

- 年度计划：一年一个文件；
- 月度计划：一月一个文件，周计划和周总结写在其中；
- 每日记录：一天一个文件，容纳状态、日记和工作日志；
- 项目文件：只为需要持续推进且有明确结果的事情创建。

## 工作流与边界

工作日使用 VS Code 和 Git 记录；宿舍电脑使用 Obsidian 阅读与整理。月底由长期 Vault 接收需要归档的内容，确认备份和迁移结果后再清理活跃仓。项目不依赖手机，也不自动提交、推送或公开私人记录。
