# 个人作品集与长期知识库网站

## 一句话介绍

`hejiahua007.github.io` 是一个基于 Jekyll 与 Chirpy 的个人网站，同时承担项目展示、技术文章发布和宿舍电脑长期 Markdown Vault 的公开出口。

## 解决的问题

个人记录天然包含私密内容，而电子简历只应该展示经过选择的成果。项目通过 `_vault` 的目录层级组织内容，并把“长期本地保存”和“公开发布”拆成两个决定：文件可以进入长期库，但只有 front matter 中明确写成布尔值 `published: true` 才会进入网站。

## 已实现

- 递归读取 `_vault`，按文件夹生成网站分类页；
- 从路径推导文章分类，并为文章生成稳定 URL；
- 公开文章的相对图片会复制到网站资源目录；
- `validate-vault.ps1` 检查 front matter 和图片引用；
- `safe-publish.ps1` 只暂存明确公开的文章及其资源；
- GitHub Actions 负责构建、链接检查和持续部署。

## 边界

仓库不是日常记录入口，也不会让模型自动决定公开范围。日常记录先进入 `life-vault`，月底迁移、整理并由人工确认后，才可能成为网站内容。
